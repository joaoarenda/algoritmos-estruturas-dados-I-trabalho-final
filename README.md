# Sistema de Gestão de Estoque e Vendas desenvolvido para a disciplina de Algoritmos e Estruturas de Dados I
Aplicação desenvolvida em Python com interface gráfica para gerenciamento de produtos, estoque e vendas.

## Funcionalidades

* Cadastro e validação de produtos;
* Busca de produtos por ID ou nome;
* Busca por nomes semelhantes;
* Registro de vendas e atualização do estoque;
* Geração de listagens do inventário em `.txt`;
* Armazenamento dos dados em arquivo CSV.

## Tecnologias

* Python
* `graphics.py`
* Arquivos CSV e TXT
